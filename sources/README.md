## «چقدر مطمئنیم»

| برچسب | یعنی |
|---|---|
| **خودش رو خوندیم** | خود صفحه، مقاله یا متن رسمی باز شد |
| **از روی گزارش** | یه رسانه یا نفر سوم نقلش کرده |
| **فقط خلاصه** | فقط خلاصه‌ی جست‌وجو دیده شد |

برچسب رو هیچ‌وقت بالاتر از چیزی که واقعاً خوندی نزن.

## قالب یک منبع

<div dir="rtl">

```markdown
### [my-source-id] عنوان کوتاه
- **کی:** اسم، کجا
- **تاریخ:** روز ماه سال
- **چی می‌گه:** یکی دو جمله، با زبان خودمون
- **حواست باشه:** چه نتیجه‌ای نباید ازش گرفت
- **سودش:** گوینده چی می‌فروشه یا چه نفعی داره
- **لینک:** https://...
- **چقدر مطمئنیم:** خودش رو خوندیم | از روی گزارش | فقط خلاصه
```

</div>

## قواعد مشارکت

1. **یک منبع، یک بلوک.** شناسه لاتین و یکتا.
2. **بدون «حواست باشه» و «سودش» پذیرفته نمی‌شه**؛ اسکریپت ساخت هم خطا می‌دهد.
3. حرف آدم‌ها **نقل به مضمون** باشد، نه نقل‌قول ساختگی.
4. بازه: سه سال اخیر. قدیمی‌تر فقط با برچسب «تاریخی».
5. مخالفِ یک ادعا را هم اضافه کن؛ منبعِ مخالف ارزشمندترین مشارکت است.
6. برای استفاده روی اسلاید: شناسه رو توی `src` همون اسلاید در `presentation/src/slides.mjs` بذار و بساز:

```bash
node presentation/build.mjs
```
