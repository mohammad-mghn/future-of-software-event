# کجا وایسادیم؟

بسته‌ی کامل یه رویداد فارسی درباره‌ی بازار نرم‌افزار در دوره‌ی AI: خوندنِ بازار بدونِ پیش‌گویی. آمارها چی می‌گن و چرا، آدم‌های بزرگ چی می‌گن و چی می‌فروشن، چی ارزون شد و چی گرون و تا کِی، استکِ خودمون کجای این نقشه‌ست، چی یاد بگیریم و چطوری، و اگه AGI برسه.

**ارائه‌دهنده:** محمد محققیان · A hard work from AMCSUI
**رویداد:** Future Software Event · اسلاتِ ۷۵ دقیقه (حدود ۵۹ دقیقه متن + پرسش و پاسخ)
**برای کی:** بیشتر دانشجوها و جونیورهای دنبال کار، تا سنیورها؛ با سه مسیرِ بازار ایران، ریموت برای خارج و مهاجرت.
**قول ارائه:** پیش‌گویی نمی‌کنیم؛ سه چیز رو یاد می‌گیریم بخونیم: **پشت عدد**، **پشت حرف**، **پشت تغییر**. هر نکته یه زنجیره‌ست: چی دیدیم ← چرا ← پس چی ← چی کار کنیم ← چرا جواب می‌ده.
**امضا:** هر خبری شنیدی: «منبعش کو؟ چی می‌فروشه؟ حالا چی گرون شد، و تا کِی؟»

## کار با ارائه

| کلید | کار |
|---|---|
| `←` یا `Space` | قدم بعدی |
| `→` | قبلی |
| `S` | منبع‌های همون اسلاید با QR بزرگ |
| `N` | متن اجرای همون اسلاید و زمان |
| `F` | تمام‌صفحه |

منبع هر اسلاید همیشه پایینش دیده می‌شه. نوار پایین صفحه بخش‌هاست؛ روش کلیک کن تا بری به همون بخش. سالنِ روشن و پروژکتور: پس‌زمینه سفیدِ خالص و حاشیه‌ی امنِ ۶۴ پیکسلی برای پروژکتورِ ۴:۳.

## ساختن

همه‌چیز از یه جا ساخته می‌شه: متن اسلاید و متن اجرای هر اسلاید کنار هم توی [`presentation/src/`](presentation/src/) هستن (`k0.mjs` شروع، `k1.mjs` تا `k6.mjs` فصل‌ها)، کمک‌تابع‌ها در `kit.mjs`، استایل در `style.css`. نسخه‌های ۳ و ۴ در `presentation/src/v3/` و `presentation/src/v4/` نگه داشته شدن. تنظیمات (ارائه‌دهنده، رویداد، آدرسِ دفترِ پیش‌بینی) در [`presentation/config.json`](presentation/config.json).

```bash
node presentation/build.mjs
```

این دستور `index.html`، `ledger.html`، `script/host-script.md` و صفحه‌ی چاپی متن اجرا رو می‌سازه، منبع‌ها رو اعتبارسنجی می‌کنه، و اگه تعداد ▶ توی متن با تعداد کلیک اسلاید جور نباشه خطا می‌ده. برای ساختن هر دو PDF روی مک (با Chrome):

```bash
node presentation/build.mjs --pdf
```

## چقدر می‌شه بهش تکیه کرد؟

- نزدیکِ ۳۰۰ منبع، هر کدوم با «حواست باشه»، «سودش» و «چقدر مطمئنیم». بیش از ۷۰ تاش روی اسلایدهاست؛ عدد فقط می‌گه چی شده، اصل کار استدلاله.
- متن اجرا حدود ۵۹ دقیقه‌ست (۱۲۵ کلمه در دقیقه به‌علاوه‌ی ۲ ثانیه برای هر کلیک)؛ بقیه‌ی ۷۵ دقیقه برای سؤال.
- چند عدد مناقشه‌برانگیزه و همون‌طور گفته می‌شه: افتِ آگهی‌های Frontend به تفکیکِ نقش (بازه و دسته‌بندی فرق می‌کنه)، آب رفتنِ مهارتِ پزشک‌ها (مطالعه‌ی ۲۰۲۶ تکرارش نکرد)، و به‌روزرسانیِ METR (خودشون می‌گن «سیگنالِ نامطمئن»). جزئیات در [`planning/v5-research-notes.md`](planning/v5-research-notes.md).
- جمله‌ی آدم‌ها عینِ متن انگلیسی‌شونه، کوتاه، با تاریخ؛ ترجمه‌ی فارسی از ماست. جایی که فقط «از روی گزارش» داریم، همون‌طور برچسب خورده.
- آگهی‌های جابینجا و جاب‌ویژن رو خودمون ۲۶ نوامبر ۲۰۲۶ شمردیم. **قبل از اجرا دوباره بشمر**، و ادعاهای سررسیده رو چک کن: Musk و Cherny (۳۱ دسامبر ۲۰۲۶)، Amodei در داووس (~۲۰ ژانویه ۲۰۲۷)، Dorsey (~فوریه ۲۰۲۷).
- «برداشتِ ما»، حکمِ نقش‌ها و جدولِ سناریوها **تحلیلِ ماست**، نه حقیقتِ ۱۰۰٪؛ همه‌شون با تاریخ در دفترِ پیش‌بینی ثبت شدن تا بشه چکشون کرد.
- **تعارض منافع:** تحقیق با Claude، محصول Anthropic، انجام شده. منبع‌های مربوط به این شرکت رو خودت باز کن.
- خطِ قرمزها: بدونِ داستانِ شخصی، بدونِ سیاست و کلمه‌های حساس، بدونِ نامِ شرکتِ ایرانی با لحنِ منفی، بدونِ تبلیغِ ابزار. اسکریپتِ ساخت این‌ها رو چک نمی‌کنه؛ `grep` کن.
