# نرم‌افزار مُرد؟ منبعش کو؟

بسته‌ی کامل یه رویداد فارسی درباره‌ی این‌که AI با Software، با شغل ما و با چیزی که باید یاد بگیریم چی کار می‌کنه.

**برای کی:** دانشجو، تازه‌کار، برنامه‌نویس، UI/UX، Founder، و کسی که به تغییر شغل فکر می‌کنه.
**نگاه اصلی:** Software پنج طبقه داره و کد فقط یکیش بود. هر طبقه‌ای ارزون شد، ارزش رفت به طبقه‌های دیگه.
**امضا:** هر حرف بزرگی شنیدی بپرس «منبعش کو؟»

## کار با ارائه

| کلید | کار |
|---|---|
| `←` یا `Space` | قدم بعدی؛ آخرین قدم هر اسلاید منبعش رو میاره |
| `→` | قبلی |
| `S` | منبع با QR بزرگ |
| `N` | یادداشت مجری و زمان |
| `F` | تمام‌صفحه |

نوار پایین صفحه بخش‌هاست؛ روش کلیک کن تا بری به همون بخش. رنگ‌ها: **زرد = کار AI، سبز = کار تو، قرمز = سؤال**.

اسم میزبان و رویداد رو توی [`presentation/config.json`](presentation/config.json) بنویس. متن اسلایدها توی [`presentation/src/slides.mjs`](presentation/src/slides.mjs) هست. بعد بساز:

```bash
node presentation/build.mjs
```

ساخت PDF روی مک:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --no-pdf-header-footer --print-to-pdf=presentation/deck.pdf "file://$(pwd | sed 's/ /%20/g')/presentation/index.html?final"
```

## چقدر می‌شه بهش تکیه کرد؟

- ۱۷۲ منبع، هر کدوم با «حواست باشه»، «سودش» و «چقدر مطمئنیم». ۸۹ تاش روی اسلایدهاست.
- حرف آدم‌ها خلاصه و ترجمه‌ست، نه جمله‌ی دقیق. ویدئوها از روی متنشون خونده شدن.
- آگهی‌های Anthropic و OpenAI رو خودمون ۲۵ نوامبر ۲۰۲۶ از صفحه‌ی عمومی‌شون شمردیم.
- نمره‌ی آدم‌ها، رنگ پنجره‌ها، تست دو سؤالی و ترتیب ۵ ساله **برداشت ماست**.
- **تعارض منافع:** تحقیق با Claude، محصول Anthropic، انجام شده. منبع‌های مربوط به این شرکت رو خودت باز کن.
- **نداریم:** پژوهشی درباره‌ی اثر AI روی شغل برنامه‌نویس ایرانی.
